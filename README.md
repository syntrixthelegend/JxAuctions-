# JxAuctions-
Lightweight, open-source Minecraft Auction House plugin for Spigot, Paper, Purpur &amp; Folia (1.18-1.21+). Features H2/SQLite/MySQL storage, SQL/Proxy/Redis/RabbitMQ multi-server sync, 16+ currencies &amp; PlaceholderAPI support, shulker previews, Discord webhooks, custom GUIs, and anti-dupe protection.
